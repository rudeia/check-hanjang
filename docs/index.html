앱은 학생의 답안·시각자료를 대신 만들거나 자동 채점하지 않습니다. 실제 제작·발표·협업·실천은 학생이 수행하며 선생님의 안내와 관찰을 따릅니다. 자료 개수만으로 성적을 판단하지 않으며 완료 차시를 보장하지 않습니다.

AI는 기초 조사·개념 이해에만 활용하세요. 과제 전체 대필, 시각 결과물의 AI 제작, 가치·태도 글의 전적 위임은 제한됩니다. 앱에는 AI 생성 기능이 없습니다.
