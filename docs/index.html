    작성·평가 안내

    무엇을 살펴보나요?

    2026학년도 보통과 2학기 통합사회2 교수학습 및 평가 운영 계획을 기준으로 안내해요. 경제 탐구는 지역의 변화·경제 개념 적용·결론과 시사점을 보고서로 설명해요. 입력 순서와 점검 목록은 글쓰기를 돕기 위한 안내예요. 별도의 채점 기준은 아니에요.

    • 인권과 불평등　자료 조사 30점, 발표 자료 제작과 실제 발표 40점, 협업과 자기 돌아보기 30점.
    • 우리 지역의 경제 변화　경제 변화 탐구 40점, 지역사회 변화 방안과 실천 30점, 발표와 협업·자기 성찰 30점.

    자료에 나온 사실과 내 생각을 구분하고, 어떤 자료를 썼는지 남겨요. 마지막 확인 목록은 스스로 빠진 내용을 살펴보는 데 쓰여요. 자료 수와 단계별 완료 표시는 작성 진행 상황이며 점수가 아니에요. 경제 탐구의 자료 3가지 이상 활용은 원본의 가장 높은 수행수준에 해당하며, 그보다 적다고 저장이나 인쇄가 막히지는 않아요. 실제 발표, 질의응답, 모둠 활동과 실천은 수업에서 진행해요.

    AI를 써도 되나요?

    기초 조사와 개념 이해에만 활용하고, 알아낸 내용은 출처에서 직접 확인하세요. 답안, 보고서·포스터, 내 생각을 담는 글은 직접 만들어요.

    사진과 공유 기기 사용

    직접 찍었거나 사용 허락을 받은 사진을 써요. 사진에 얼굴, 이름, 집 주소가 나오지 않는지 확인하세요. 공유 기기에서는 파일을 안전한 곳에 보관한 뒤 작업을 초기화하고, 내려받기 폴더에 남은 파일도 정리하세요.
