# 체크 한장

통합사회2의 인권·사회/공간 불평등 과제와 경제 탐구 보고서를 위한 학생 직접 작성 탐구 작업장입니다.

목표 → 평가 증거 → 활동의 교사 설계와, 문제 → 사실 → 비교·해석·판단 → 사례의 잠정 결론 → 개념 관계·조건·전이 → 제안·표현 → 실제 수행·성찰의 학생 경로를 연결합니다. 일반화·전이는 새 채점요소가 아닌 학습 지원입니다. 짧은 메모로 시작할 수 있고 발표 대본·학생 정보 같은 확장 기록은 필요할 때 엽니다. 실제 제작·발표·협업·실천과 교사 관찰을 대신하지 않습니다.

## 실행
`docs/index.html`을 정적 웹 서버로 제공합니다. GitHub Pages에서는 `/docs`를 배포 원본으로 사용합니다.

## 데이터와 개인정보
- 답안, 자료 목록, 첨부 사진은 해당 브라우저의 localStorage에 저장됩니다. 서버 제출·자동 채점·AI 답안 생성 기능은 없습니다.
- 기존 사이트와 GitHub Pages는 서로 다른 주소여서 기존 기록이 자동 이동하지 않습니다. 필요한 경우 기존 사이트에서 JSON 백업을 직접 내려받아 새 사이트에서 복원하세요.
- 공용 기기에는 다른 사용자가 기록을 볼 수 있습니다. 내려받은 백업과 보고서도 안전하게 보관하세요.
- 외부 자료 링크 및 펼친 참고사진은 해당 제공업체로 연결됩니다. 학생의 답안은 전송하지 않습니다.
- 실제 시각자료 제작·발표·협업을 앱 기록으로 대체하지 않습니다.

## 검사

테스트는 격리된 가상 저장소를 사용합니다. 이미지 디코딩과 키보드 일부는 모의 동작이므로 실제 모바일 기기, 사진 업로드, 인쇄/PDF 결과 검증을 대체하지 않습니다.

## 공개 범위
정적 애플리케이션 소스와 테스트만 포함하며 학생의 작성 데이터, 개인 사진, 백업 파일, 비밀 키, 기존 배포 서비스의 설정은 포함하지 않습니다. 참고사진은 원본 링크와 제작자·라이선스를 앱 내에서 표시합니다.

## 기록 호환성
- 저장 키 `pyeongga-hanjang-social2-v1`, schema `assessment-one`, version `1`과 기존 27개 답안·자료 7개 필드·사진·체크를 보존합니다. 읽기·렌더링만으로 저장하거나 마이그레이션하지 않습니다. 이전 현황·요약을 새 사실·해석 기록으로 자동 분류하지 않습니다.
- 인권 기록은 루트에 남고 경제 기록은 `economy` 객체에 분리됩니다. 과제 선택은 `inquiry: {version: 1, active: "human" | "economy"}`로 저장합니다. 새 답도 문자열이며 자료의 새 사실·비교·해석 필드도 문자열 확장입니다. 사진은 과제별 기존 4장·변환/저장량 제한을 적용합니다. 백업은 두 과제를 모두 포함합니다.
- `learning: {version: 1, links: {답안키: [자료ID]}}`와 자료의 `_id`는 명시적인 근거 연결 때 추가됩니다. 자료를 삭제해도 ID를 다른 자료로 재배정하지 않으며, 삭제된 연결은 경고하고 학생이 정리합니다. 과제 전환·자료 삭제·사진 추가·복원은 저장 성공 후에만 반영합니다.
- 미지원 확장 버전·잘못된 과제 데이터·중복 자료 ID는 자동 저장을 중단합니다. 복원 시 비활성 과제의 사진도 확인합니다.

## 구현과 검증 범위
`app.js`는 기존 저장·복원과 호환 경로, `media.js`는 과제별 사진 안전 처리, `inquiry.js`는 새 학생 경로와 교사 안내·근거 연결·보고서를 담당합니다. 기존 두 테스트는 호환 코어를, `inquiry.cjs`는 새 화면 계층을 함께 읽어 두 과제와 확장 데이터·삭제/백업/복원·저장 실패·인쇄 직전 보고서·사진 전환 중 경쟁 상태를 확인합니다. 자동 검사는 가상 데이터와 모의 이미지 디코딩을 사용합니다.

### 전이 상황과 마지막 활동 위치
- `transferContext`는 명시적으로 선택한 가상/학생 지정 상황을 저장합니다. 학생 답은 기존 `answers.transfer`에 따로 남습니다. 답을 입력하거나 ‘현재 답을 선택한 상황에 연결’을 누를 때만 `answerContext`에 그 상황을 연결합니다. 상황만 바꾸면 이전 답의 상황은 유지하고 보고서에서 현재 선택과 구분합니다. 과제별로 분리되며 백업에 함께 포함됩니다.
- 선택적인 `position: {version: 1, group, index, extra?}`는 과제별 마지막 활동과 확장 기록 위치입니다. 읽기만으로 추가하지 않으며 기존 기록에는 legacy `step`에 따른 기본 위치를 사용합니다. 과제별 활동 수·자료 수·허용된 확장 키를 검증하고 잘못된 위치 메타데이터는 기존 보호 절차로 처리합니다. 저장 실패 시 이동은 임시 상태로 남고 경고와 백업으로 보관할 수 있으며 기존 디스크 기록은 바뀌지 않습니다.
- 기본 보고서에는 안전한 http(s) 출처의 전체 URL 또는 책·문서 위치를 글자로 표시해 종이 출력에서도 확인할 수 있게 했습니다.

### 검토 보완
- 전이의 학생 지정 초안은 선택 모드와 별개인 `transferContext.studentDraft` 문자열로 과제별 보존합니다. 가상 상황으로 바꿨다가 돌아와도 초안이 남고, 답을 작성할 때의 `answerContext` 스냅샷은 별도로 유지됩니다. 기존 기록을 읽기만 해서는 확장 필드를 추가하지 않습니다.
- 앞쪽 참조는 질문·직전 답·현재 자료 또는 선택 근거의 짧은 발췌만 보여 줍니다. 모든 원문 기록은 기본적으로 접힌 전체 참조에서 확인하며 저장된 텍스트를 줄이거나 바꾸지 않습니다.
- 출처 선택은 분석·판단·결론·제안 등 관련 항목에 표시합니다. 실제 수행·역할·협업·성찰은 경험 기록으로 안내하고 새 출처·업로드 요건을 만들지 않습니다. 이전에 저장한 연결은 보고서와 백업에 보존됩니다.
- 과제별 경제 질문·도움말을 구분하고, 평가요소·배점과 확인할 증거를 나누어 표시합니다. 주제의 뉴스·자료 이동 링크, 관련 단계의 짧은 선택 사례 힌트를 유지합니다. 자료별 읽기와 여러 자료의 종합 질문을 구분하며 기본 활동 수(인권 26·경제 28, 자료 1개 기준)는 늘리지 않았습니다.
- JSON 복원 한도는 실제 파일 크기 5MiB입니다. 내보내기도 실제 UTF-8 Blob 바이트를 같은 한도로 확인하며, 초과 파일은 현재 앱에서 바로 복원할 수 없다고 알리고 원본 전체 다운로드는 계속 제공합니다. 텍스트·미저장 입력·사진을 자르거나 입력 분량을 제한하지 않습니다.

### 선택 역할·미션
주제 시작 화면에서 정책 운영 담당자·시민단체 회원·지역 기자·연구자·특정 주제 담당자의 관점 또는 직접 정하기를 선택하고, 누가 읽으면 좋을지와 무엇을 이해하면 좋을지를 짧게 적을 수 있습니다. 선택 없이 진행할 수 있고 활동 이동 메뉴나 맥락 힌트에서 언제든 바꿀 수 있습니다. 기본 활동 수를 늘리거나 새 필수입력·채점요소를 추가하지 않았습니다. 관점 선택은 직업 연기나 실제 신분을 뜻하지 않습니다. 모든 관점에서 다른 설명·반대 자료·한계를 살피며 경제 연구자 관점에서는 경제개념으로 변화 설명과 관계·인과의 구분을 안내합니다.

과제별 선택 확장 `mission: {version: 1, enabled, choice, customRole, audience, purpose}`에 저장합니다. `choice`는 `none/policy/advocate/journalist/researcher/specialist/custom` 중 하나입니다. 직접 쓴 역할 초안·독자·목적은 관점 전환·건너뛰기 때 지우지 않습니다. 기존 `answers.role`은 실제 협업 역할로 남으며, 관점 변경은 앞선 사실·해석·결론을 변환하지 않습니다. 선택 변경은 저장 성공 후 적용하고 텍스트의 저장 실패 시 임시 입력과 백업을 보존합니다. 읽기만으로 확장 필드를 쓰지 않으며 잘못된 확장 데이터는 기존 보호 절차를 따릅니다.

탐구 중에는 짧은 관점·독자·목적 힌트를, 보고서에는 ‘선택한 탐구 관점 · 가상 설정’과 ‘○○의 관점에서 탐구함’을 표시합니다. 학생의 독자·목적과 실제 협업 역할 기록을 구분하며 사실·해석·결론은 생성하지 않습니다. 사용하지 않는 선택 기록은 전체 기록 부록과 백업에 보존합니다.

실제 수행 단계와 실제 경험 확장 기록의 관점 힌트는 독자·목적을 유지하되 ‘실제로 한 일과 받은 질문을 기록해요. 가상 관점과 실제 수행은 구분해요.’로 안내합니다. 이 화면에는 방안 탐색·반대 자료 확인 지시를 반복하지 않습니다. 연구자 안내는 ‘함께 변했다고 해서 원인이라고 단정하지 않아요.’처럼 쉬운 말로 표시합니다.

## 미션 중심 탐구 경험 보완
역할을 고르지 않아도 시작 화면에 공통 임무와 조사해서 만들 결과물이 표시됩니다. 정책 운영 담당자·시민단체 회원·기자·연구자·특정 주제 담당자의 임무 제안은 결론이나 찬반을 정하지 않으며 학생이 명시적으로 채택·수정·건너뜁니다. `mission.task`, `mission.product`는 선택적인 문자열 확장이고 기존 관점·독자·목적·협업 역할과 답안을 보존합니다. 역할별 대상·비용·실행조건, 당사자 영향·권리·다른 의견, 사실확인, 비교조건·개념·한계는 같은 기존 필드의 질문 초점으로 반영합니다. 기본 활동 수와 필수입력은 늘리지 않습니다.

반복 역할 안내 대신 현재 활동의 목적·행동·남길 기록과 결과물 연결을 짧게 표시합니다. 결론 활동은 자신의 비교·해석, 제안은 자신의 결론, 전이는 자신의 일반화·조건을 접힌 참조에서 다시 읽습니다. 두 과제 모두 상위 수준의 다양한 신뢰 자료 3가지 이상과 분석 등의 요구를 안내하며, 자료 3개만으로 A라고 판정하거나 다음 활동 이동을 막지 않습니다. 배점은 인권 30/40/30·경제 40/30/30을 유지합니다.

기존 `topic`은 주제로 보존하고 선택 문자열 답안 `posterTitle`로 결과물 제목을 고칠 수 있습니다. `message`를 큰 핵심 메시지로, `learning.links.chosenEvidence`의 안정적 자료 ID를 핵심 근거 영역에 표시합니다. 선택하지 않은 자료·기본/추가 출처 필드·모든 답안은 전체 출처와 부록에 남습니다. 형식 선택에 따라 포스터·문서·발표 구성의 배치를 달리하고 빈 입력칸 나열을 줄입니다. 모든 내용은 학생이 쓴 기록을 그대로 사용하며 사실·해석·결론을 합성하지 않습니다.

결과물에서 제목·메시지, 핵심근거, 시각물, 발표준비, 실제수행 기록으로 직접 돌아갈 수 있습니다. 표현 단계의 발표 준비 연결은 기존 `opening/body/closing/qa`를 재사용하며 실제 수행과 구분합니다. 선택 위치 `presentationPrep`은 이 준비 묶음의 복원을 지원합니다.

인쇄 버튼은 최신 보고서를 한 번 구성해 이미지 디코딩을 기다리고, `beforeprint`가 준비한 이미지 DOM을 다시 교체하지 않게 합니다. 브라우저 인쇄는 변경된 기록이 있을 때만 보고서를 갱신합니다. 디코딩 실패·인쇄 준비 중 기록 변경은 실패를 알리고 인쇄하지 않습니다. 브라우저 인쇄에서 사진 준비가 확인되지 않으면 화면·인쇄 경고를 표시합니다.

검증 한계: 합성 PNG를 사용한 Chrome 파일 선택 작업이 사용자에 의해 중단됐으며 적용 여부를 확인하지 못했습니다. 따라서 이 버전의 실제 이미지 업로드와 이미지 포함 PDF 결과는 미검증입니다. 모의 디코딩 테스트를 실제 브라우저 업로드/PDF 검증으로 간주하지 않습니다.
